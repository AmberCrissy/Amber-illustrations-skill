# Amber 个人 IP

## 身份锚点

每张图至少清楚保留以下三个最强特征：

1. 头顶红色墨镜，这是全套视觉中唯一的强红色。
2. 黑色长卷发，发尾只有少量暖金棕线条。
3. 浅蓝色宽松翻领衬衫、奶油白阔腿裤，以及腰间一条窄小的明黄丝巾或腰带点缀。

辅助特征包括小圆环耳饰和黑白休闲鞋。身份参考图位于 `assets/amber-character-reference.png`。

## 固定比例

- 使用约 3–3.25 头身的等比例 Q 版：头部明显放大、四肢和躯干同比缩短，但不是两头身婴儿比例。
- 人物轮廓紧凑，宽松衬衫和阔腿裤的垂坠关系仍要清楚。
- 全身、坐姿、行走与操作姿势都维持同一 Q 版比例，不在同一组图里突然变成长身人物。

## 性格与表现

Amber 温柔、松弛、好奇、专注，带一点聪明的冷幽默。她不是站在场景旁讲解的主持人，而是系统里的实际操作者：拆词元积木、整理上下文桌面、从记忆档案柜取资料、插接工具、搭建护栏、驾驭复杂系统。

表情以专注、思考、略带狡黠和自信放松为主。用眉毛、眼睛方向和嘴角的小变化增加生命力；保持亲和，但不要过度卖萌、夸张腮红或表情包化。

## 简化规则

- 五官使用点状眼睛、短眉和小嘴，不画高光大眼、浓睫毛与复杂腮红。
- 红色墨镜始终在头顶，除非画面动作明确需要她戴上。
- 头发使用一个清楚的外轮廓和少量内部波浪线，不画写实发丝；金棕色只在发尾轻点。
- 浅蓝衬衫保持无图案、低细节，袖口自然卷起；腰间明黄点缀保持很小。
- 可使用全身、半身或小比例角色；同一组图保持头身比例基本一致。

## 禁止

- 不要把 Amber 画成金发、直发、短发、深棕 T 恤或无袖西装马甲。
- 不要把红色用于其他物件、箭头或警示，避免削弱红墨镜的身份识别。
- 不要变成写实肖像、时尚杂志人物、日系萌系大头贴或儿童卡通吉祥物。
- 不要照搬参考图的角色设定表、贴纸合集、米色纸纹和满版布局。
- 不要让 Amber 只站在角落指向一张已经完整成立的图表。

判断标准：如果去掉 Amber，核心隐喻仍完全成立，就要改写画面，让她成为动作主体。
