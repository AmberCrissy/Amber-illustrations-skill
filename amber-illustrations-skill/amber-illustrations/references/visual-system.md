# 视觉系统

## 风格 DNA

纯白、极简、手绘、留白、清楚、克制、轻微怪诞，像产品设计师在白纸上画出的概念草图。

- 画面比例 16:9。
- 主体占画面约 40%–60%，保留至少 35% 安静白区。
- 人物、家具、机器、箭头和文件使用同一种黑色细线，线条轻微抖动、轮廓略圆润；不允许人物精细而物件简陋，或反过来。
- 配色固定为浅蓝 `#BFD7EA`、奶油白 `#F6F0E3`、明黄 `#F5C542`、炭黑线条。红色 `#D83A34` 只用于 Amber 的墨镜。
- 浅蓝用于文件夹、书、椅面、机器面板和次级信息块；明黄用于把手、按钮、铰链、插头、笔和路径等“发生作用的连接点”。
- 图像先靠动作和物件表达，再用少量短中文补充。

## 可选结构

- 前后对比：同一角色处在两种状态。
- 系统局部：放大一个关键连接或断点。
- 概念隐喻：把抽象词变成可操作的实体。
- 路线或闭环：Amber 亲自搬运、连接或推动信息。
- 分层空间：桌面、档案柜、工位、护栏等空间关系。
- 小分镜：最多 2–3 格，展示状态变化。

## 连续文章的统一性

同一篇文章可以共享世界观、角色和少量重复物件，但每张图必须有不同的核心动作和主构图。不要复刻旧案例，也不要把所有概念塞进一张总览图。

## 元素语言

- 文件夹与书：浅蓝平涂、黑色圆角细线、一个明黄扣点。
- 椅子与桌子：极简管状框架，浅蓝接触面，明黄只落在连接处。
- 机器与工具：奶油白主体、浅蓝面板、明黄按钮或插头；避免灰色工业写实感。
- 箭头与路径：明黄手绘曲线，少量使用；不要再用橙色主路径。
- 装饰信号：以蓝黄小点、短线或小方块为主，不使用红心、红星和满版涂鸦。
