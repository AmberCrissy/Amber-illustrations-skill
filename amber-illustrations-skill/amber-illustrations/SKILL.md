# Amber 正文配图

## 目标

把中文文章里的关键判断、流程、关系、状态或隐喻，转成清爽、易懂、略带荒诞感的 16:9 手绘解释图。固定主角是 Amber；她必须亲自参与画面的核心动作，不能只是装饰。

## 按需读取

- 涉及 Amber 外观、性格或动作时，读取 `references/amber-ip.md`。
- 规划画面风格和构图时，读取 `references/visual-system.md`。
- 实际生成图片时，读取 `references/prompt-template.md`。
- 生成后检查时，读取 `references/qa-checklist.md`。
- `assets/amber-character-reference.png` 是已确认的 Amber Q 版角色与配套元素参考图。生成时同时参考人物比例、服装、线条密度和物件语言，但不要照搬设定表版式。

## 工作流

1. 阅读用户提供的正文、Markdown、截图或主题，提炼认知锚点。不要平均配图。
2. 优先选择需要“看一眼才能懂”的内容：对比、流程、层级、关系、系统状态、认知转折和贯穿全文的总隐喻。
3. 只要求规划时，输出简洁 shot list：插入位置、核心意思、结构、Amber 的动作、主要物件和短标注。
4. 明确要求生成时，每张图单独调用图像生成工具，不要把多张图拼成一张。
5. 一张图只表达一个主要认知动作。跨图保持 Amber 的发型、墨镜、服装和整体比例一致，但为当前内容重新发明隐喻。
6. 生成后按质检清单检查；身份漂移、画面过满、文字错误或 Amber 只是装饰时，优先局部编辑或重生成。

## 默认视觉要求

- 16:9 横版正文配图，纯白背景。
- 人物与物件使用同样纤细、略带抖动的手绘线条和同一级别的简化细节。
- 浅蓝与奶油白为大面积基础色，明黄色用于连接点、路径和小物件；红色只用于 Amber 头顶的墨镜。
- 中文标注最多 3–6 处，每处尽量 2–6 个字；不依赖文字才能看懂。
- Amber 固定为约 3–3.25 头身的等比例 Q 版，通常占画面 15%–30%，复杂动作可适当放大。
- 不要左上角类型标题，不要 PPT 网格、复杂架构、商业海报、真实 UI 或儿童绘本感。

## 保存与交付

项目内图片保存到 `assets/<article-slug>-illustrations/`，按 `01-topic-name.png` 顺序命名，不覆盖已有文件。交付时说明每张图的用途、保存路径，以及哪些是主图、哪些可选。
